# MBN Строй

## Project

MBN Строй

## Purpose

Сайт компании по ремонту квартир и домов в Туле.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Local development

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).
